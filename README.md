I'm a full-stack developer and sysadmin who builds things end-to-end — from writing the code to deploying the infrastructure. I created **DentalPM Madagascar**, a multi-tenant SaaS platform for dental practices, entirely from scratch.

My stack covers both sides: web development (Node.js, React, PostgreSQL) and infrastructure (Ansible, Docker, WireGuard, Prometheus). I also participate in CTF competitions and enjoy open-source tooling.
